# SelfWindow · 屏幕透视校正

针对倾斜摆放的副屏，把整个 Windows 桌面映射到可拖动的四边形。支持横屏、竖屏、反向竖屏、混合 DPI 和负坐标的多显示器布局。完全本地运行，没有收费、网络通信或第三方运行时依赖。

新版增加视点标定、可调圆柱曲面和 4×4 Bézier 局部微调，保留原来的四角校准。

## 运行

从 [GitHub Releases](https://github.com/YaoYao-Pig/SelfWindow/releases) 下载 Windows x64 压缩包，解压后运行 `SelfWindow.exe`，无需安装或管理员权限。自行构建的文件位于 `dist\SelfWindow.exe`。

程序会在系统托盘后台运行，并恢复上次已开启屏幕的校准；双击托盘中的绿色屏幕图标打开设置。再次运行同一个 exe 也会打开现有设置窗口，不会启动第二份程序。手动启动后保持后台运行，不添加开机自启动。

若旧的测试版本仍开着，请先退出旧版本，再打开此文件。可通过 `SelfWindow.exe --settings` 直接显示设置窗口。

1. 在下拉框选择目标显示器；列表显示实际像素尺寸和横竖方向。初次打开默认选最右侧的屏幕，可用 **识别屏幕** 确认目标。
2. 点击 **开启此屏校正**。可以先勾选 **显示校准网格**，坐在平时的位置观察屏幕。
3. 在控制窗口的竖屏预览里拖动四个彩色圆点。它们依次对应左上、右上、右下、左下。移动较近一侧的角，直到实际屏幕上的网格从你的坐姿看起来方正。角点只能在屏幕范围内，不会把桌面裁到屏幕外。
4. 点击一个角点后，方向键按实际屏幕 **1 像素**微调，`Shift + 方向键`为 10 像素。拖动结束和键盘调整后自动保存，也可点 **保存参数**。
5. 取消 **显示校准网格**，即可使用实时桌面。网格开启时，下面的桌面仍会接收输入，因此在网格模式下请通过主屏上的控制窗口调整。

每台显示器、每个旋转方向的参数和开启状态独立保存。可先开启一个屏幕，再切换选择并开启另一个。升级自旧版时，已有非默认校准参数的显示器会自动应用；全新安装没有校准参数时保持暂停，双击托盘图标设置即可。

## 曲面与视点设置

点击主窗口右侧 **曲面与视点设置…**，选择：

- **四角透视**：沿用旧版校准；拖动四个角。
- **视点标定 · 正对的平面**：根据实际屏幕尺寸、观看位置与倾斜角度，按相同像素视线计算补偿。
- **视点标定 · 可调圆柱曲面**：将理想桌面组织在虚拟圆柱上，再投射到实体屏幕。曲率为 0 时与平面模式一致；正、负曲率可比较两个弯曲方向。

宽度、高度、前后距离和眼睛偏移以厘米计。默认尺寸是示例值，不能代替实物测量；尺寸和偏移输入后点 **应用尺寸和偏移**。左右倾斜、上下倾斜、曲率滑条即时生效。角度正值分别表示屏幕右边、下边更远；眼睛偏移正值分别表示眼睛在中心的右方、下方。前后距离是在未旋转参考坐标中，眼睛到屏幕中心的前后分量。

圆柱模式可选择 **左右弯曲（绕竖轴）** 或 **上下弯曲（绕横轴）**。后者便于调节长竖屏上部和下部的观感。轴按照观看方向定义，横竖屏的旋转不会错误交换轴。曲率 100% 对应以当前眼点为圆柱中心的半径，降低绝对值会增大半径、逐渐变平；这是一种可选的目标画面模型，并不保证比准确的平面校正更自然。

程序自动缩小虚拟内容，保证完整画面能放进实体屏幕；主窗口显示实际缩放比例。倾斜越大，有效画面可能越小。

勾选 **在主窗口编辑 4×4 局部曲面网格** 后，可拖动主预览的 16 个圆点，微调边缘与中间。这里使用三次 Bézier 残差曲面，拖动一个点也会平滑影响邻近区域。方向键移动选中的显示位置 1 像素，Shift 加速到 10 像素。会造成屏幕越界、边界相交或网格折叠的修改不会应用，保留上一组有效参数。**清除局部微调** 只清除网格偏移，保留四角、模式和观看参数。

各模式共享局部微调层；已有微调阻止大幅改变观看参数时，可先清除微调，再设定模型。切回四角模式后，原来的四角参数仍在；要完全比较旧版效果，还需清除局部微调。

旧配置可直接读取。首次保存新版参数前，会在配置目录保留 `settings.ini.v1-backup.ini`。模式、曲率、轴向、观看参数和局部网格均按显示器及其旋转方向保存。

## 开关和恢复

- **Ctrl + Alt + F10**：开关当前选择的显示器。
- **Ctrl + Alt + F12**：立即停止所有屏幕校正，恢复正常鼠标。
- **恢复全部屏幕**按钮：恢复原画面，并记住暂停状态，下次启动不会重新应用。
- 关闭设置窗口、最小化或点 **隐藏到托盘，继续校正**：继续后台校正，不占用任务栏。隐藏时自动关闭测试网格，显示实际桌面。
- 托盘右键菜单可打开设置、开关当前屏幕、恢复全部屏幕或 **退出 SelfWindow**。退出会恢复原画面，下次手动启动仍记住退出前开启的屏幕。
- **重置四角**：把当前屏幕恢复为完整矩形，并保存参数。
- 显示器旋转、分辨率变化或系统休眠时自动停止校正，重新检测后可手动开启。

运行期间会有第二个同名的恢复保护进程。主程序退出后它会恢复系统鼠标并退出；如果主界面持续无响应，它会结束本工具并恢复鼠标。不要单独关闭这个保护进程。

配置位于 `%LOCALAPPDATA%\SelfWindow\settings.ini`，不改 Windows 分辨率、缩放、显示器布局或鼠标主题。

## 工作方式和适用范围

- Windows Graphics Capture 按显示器当前方向捕获，避免将竖屏当成横屏处理。
- 未添加局部微调的四角模式保留原版精确单应性透视路径。物理平面／圆柱与 Bézier 模式用自适应细分网格渲染；仅参数改变时重建网格，普通帧继续使用 GPU 采样。
- 输出层排除自身捕获，避免画面重复嵌套。
- 画面与鼠标热点使用同一变换；网格模式的鼠标映射使用 GPU 实际三角形的重心插值，避免分别拟合两条映射造成点击错位。Windows 保持原来的逻辑鼠标位置，显示的鼠标跟随变形后的按钮；点击、键盘和拖动仍由原程序处理。软件不注入鼠标事件、不挂钩其他程序。
- 在未校正的屏幕上恢复系统原生鼠标。校正屏幕内的软件鼠标保持自身形状，热点位置随透视变换。

当前版本面向普通 SDR 桌面应用。系统可能显示屏幕捕获提示边框。HDR 色彩、受保护视频、独占全屏游戏、触摸/笔输入和安全桌面未做兼容保证。画面有一次捕获/显示延迟；跨屏时光标在校正边缘可能跳动。没有改变 Windows 的窗口布局范围，所以最大化窗口仍占据整个逻辑屏幕，并映射到校准四边形。

软件能纠正固定观察点的几何透视，不能消除面板侧看偏色，也不能保持任意头部位置都正确。留出的黑边和缩小后的文字清晰度损失属于几何校正的代价。

## 构建

需要 Visual Studio 2022 C++ Desktop 工具和带 C++/WinRT 的 Windows 10/11 SDK：

```powershell
pwsh -NoProfile -File .\build.ps1
```

输出为 `dist\SelfWindow.exe`。发布版静态链接 C++ 运行库，Windows 10 2004+ / Windows 11 x64 可运行；使用系统自带 D3D11、WGC 和 Magnification API。

## 验证

```powershell
.\dist\SelfWindow.exe --self-test .\test-output
.\dist\SelfWindow.exe --diagnostics .\test-output
.\dist\SelfWindow.exe --integration-test .\test-output
.\dist\SelfWindow.exe --background-test .\test-output
```

第三项会在每台屏幕短暂显示合成测试图，结束后自动关闭。第四项使用独立配置测试后台运行，并短暂开启一个屏幕的原比例输出。运行第四项前需先退出已运行的 SelfWindow。不要在演示、录屏或其他重要操作中运行显示测试。测试结果写入指定目录；集成测试截图仅包含合成网格，不保存个人桌面。

当前版本的本机验证记录：

- 1,374 项几何检查：四角映射、透视逆变换、鼠标热点对齐、横竖屏比例、负坐标和无效四边形。
- 13,173 项新增检查：射线平面模型与单应性等价、曲率归零、圆柱双轴、反向曲率、混合尺寸、局部微调、无效网格和 GPU 三角形对应的鼠标映射。
- 四屏捕获和 GPU 输出：1440×2560 / 90°、2560×1440 / 0°、1920×1080 / 0°、2160×3840 / 270°。
- 对照合成图的四角颜色验证旋转方向、透视渲染、黑边及输出层不会被再次捕获。
- 在四块屏幕各验证四个新增场景，用 GPU 颜色渐变采样和 CPU 鼠标位置对照，共 784 个采样点；覆盖平面、圆柱双轴、反向曲率叠加局部网格。
- 界面开启、拖动四角和 Ctrl+Alt+F12 恢复验证。初始窗口大小按系统 DPI 缩放。
- 后台模式提供 `--background-test` 集成测试：独立测试配置、托盘图标注册、隐藏启动、恢复已启用显示器、关闭窗口后继续校正、重建托盘、紧急恢复及完全退出。
- 新版模式、观看参数和局部网格的保存／重载，以及切回旧四角模式的兼容测试。

真实应用的长时间点击、拖动、跨屏体验和异常退出保护仍需在实际使用中进一步验证。

## 项目结构

- `src/main.cpp`：显示器管理、校准界面、托盘、配置与测试入口。
- `src/graphics.cpp`、`src/graphics.h`：Windows Graphics Capture 与 Direct3D 11 渲染。
- `src/geometry.h`：四点单应性变换和校准有效性检查。
- `src/warp.h`：视点射线模型、圆柱曲面、Bézier 残差、自适应网格与前向鼠标映射。
- `src/view_controls.h`：模式、尺寸、观看位置、曲率及网格设置窗口。
- `src/cursor.h`：鼠标热点映射与软件光标显示。
- `tests/warp-tests.h`：模型等价、精度、输入校验与鼠标映射回归检查。
- `build.ps1`：本地构建和便携版输出。
